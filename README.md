# kernTech — Site MPA

Protótipo acadêmico de uma empresa fictícia de serviços de TI, com uma landing page central e seis páginas individuais de serviços.

## Estrutura

- `index.html`: landing page, catálogo, campanha e contato.
- `servicos/*.html`: seis páginas independentes.
- `styles.css`: estilos responsivos, com azul (#163D77), verde (#059669) e roxo (#8B5CF6).
- `services.js`: catálogo compartilhado.
- `script.js`: geração dos cartões, formulário demonstrativo e menu móvel.

As imagens são provisórias e carregadas do Unsplash. Antes da entrega, substituir por fotografias originais e versões editadas por IA de cada integrante.

O formulário é **demonstrativo**: não envia nem armazena dados.

Abra `index.html` no navegador ou hospede na raiz do GitHub Pages.
